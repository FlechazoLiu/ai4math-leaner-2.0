## 1. 开始使用

### 账号创建
账号由管理员统一创建。你会收到一个 **学号**，初始密码就是你的 **学号**。

> **教师、助教、管理员账号**：初始密码为 `default123456`（不是学号），使用邮箱地址登录。

### 首次登录
1. 在浏览器中打开平台地址
2. 默认选中 **Student ID（学号）** 登录模式
3. 输入你的 **学号**，密码也输入学号
4. 首次登录后需要 **修改密码**
5. 输入新密码（至少 6 位），确认后提交
6. 用新密码重新登录

### 修改密码
登录后点击右上角用户名 → **Change Password**。输入当前密码和新密码即可（无需填写邮箱）。

### 忘记密码
联系你的老师或管理员重置密码。

## 2. 仪表盘

登录后进入**仪表盘**，你会看到：
- 欢迎信息
- 已加入的课程列表

左侧**侧边栏**是主要导航：

| 功能 | 说明 |
|------|------|
| **Dashboard** | 首页 — 查看已选课程 |
| **Courses** | 浏览所有课程 |
| **Exercises** | 浏览练习题 |
| **My Answers** | 查看所有提交记录和成绩 |
| **Resources** | 学习资料 |

## 3. 浏览课程

### 查看已选课程
在 Dashboard 或 **Courses** 页面可以看到你已加入的所有课程。

### 课程内容
点击课程卡片进入课程页面，包含：
- **Notifications** — 老师发布的通知
- **Assignments** — 需要完成的作业
- **Posts** — 讨论和公告

### 选课
学生不能自助选课。如需加入课程，请联系你的老师或管理员。

## 4. 练习题与提交答案

### 查找练习
1. 点击侧边栏 **Exercises**
2. 按标题、标签或难度筛选
3. 点击任意练习查看详情

### 提交答案
1. 在练习详情页点击 **Submit Answer**
2. 你会看到题目描述和形式化描述（如果有）
3. 提交两部分内容：
   - **自然语言答案**（必填）— 用文字解释你的解法（支持 Markdown）
   - **形式化答案**（可选）— 编写 Lean 4 代码
4. 选择操作：
   - **Save as Draft** — 保存草稿（不会提交评阅）
   - **Submit Answer** — 提交评阅（提交后不可修改）

### Lean 验证
如果你提交了**形式化答案（Lean 4 代码）**且验证器已启用，系统会自动用 Lean 4 编译器检查你的代码。

**验证状态说明：**

| 状态 | 含义 |
|------|------|
| **Pending** | 代码正在排队等待验证 |
| **Verified** | Lean 代码编译成功，没有错误 |
| **Failed** | Lean 代码编译出错——答案下方会显示具体的错误信息 |
| **Not Verified** | 未提交形式化答案，或验证不适用 |

验证状态会显示在你的答案下方。如果验证失败，Lean 编译器的具体错误信息会展示出来，方便你调试。

### 编译失败后重新提交
如果 Lean 代码**验证失败**，你会在答案旁看到 **"Revise & Resubmit"** 链接。点击后可以修改 Lean 代码并重新提交。重新提交没有次数限制。

### 被退回的作业
如果老师或助教将你的作业退回（例如要求修改），你的答案会自动恢复为草稿状态，分数被清除。你可以修改后重新提交。

> **注意**：重新提交被退回的答案时，系统会自动重新触发 Lean 验证。即使你没有修改形式化代码，重新提交也会触发全新验证。

## 5. 查看答案与成绩

点击侧边栏 **My Answers** 查看所有提交：
- **状态**：草稿 / 已提交 / 已批改
- **验证状态**：待验证 / 通过 / 失败
- **分数**：老师的评分

点击 **View** 查看答案详情和老师反馈。

## 6. 作业

作业是老师布置的计分任务。

### 查看作业
打开课程 → **Assignments** 标签页 → 点击作业开始作答。

### 回答作业题
1. 每个作业包含一个或多个题目
2. 每道题提交自然语言和/或形式化答案
3. 可以单独保存每道题
4. 所有题目答完后，点击 **Submit Assignment**

> **注意**：作业一旦提交即为最终版本，不可修改。

### 查看成绩
老师批改后，分数和反馈会显示在作业页面。你也可以在 **My Answers** 中查看。
