## 1. 开始使用

### 账号设置
管理员会为你创建账号，分配 **Assistant（助教）** 角色。

你的登录标识为管理员设置的**邮箱地址**或**学号**。

### 初始密码
- **教师、助教、管理员**：初始密码为 `default123456`
- **学生**：初始密码为**学号**（与 staff 账号不同）

> 账号创建时 `must_change_password = true`，首次登录必须修改密码。

### 登录
1. 输入你的**邮箱地址**或**学号**（管理员设置的）
2. 输入初始密码 `default123456`
3. 首次登录会提示**修改密码**
4. 输入新密码（至少 6 位），确认后提交
5. 用新密码重新登录

### 访问所管课程
老师将你设为某门课程的助教后，点击侧边栏 **Review Workbench**，课程会自动出现在课程下拉列表中。

## 4. 批改作业

### 进入批改工作台
点击侧边栏 **Review Workbench**，进入新的批改界面。

### 批改流程：课程 → 作业 → 题目 → 评分

**第一步：选择课程**
- 使用顶部的**课程下拉框**（默认选中第一个课程）
- 只会显示你被分配为助教的课程

**第二步：选择作业**
- 显示该课程下所有已发布的作业
- 点击作业旁的 **Grade** 按钮
- 进入该作业的批改页面，显示所有题目

**第三步：选择题目**
- 每道题显示**进度条**（已批改/总数）
- 点击题目的 **Grade** 按钮开始批改
- 进入逐题批改页面

**第四步：逐份批改学生答案**

批改页面**一次显示一位学生的完整答案**：
1. **学生信息栏** — 姓名、验证状态、提交时间
2. **答案内容** — 左右分栏展示：
   - 左：**自然语言答案**（Markdown 渲染）
   - 右：**形式化 Lean 4 代码**（语法高亮）
3. **评分输入** — 输入 0–100 分，实时颜色预览
4. 点击 **Submit & Next** → 自动跳转到下一位未批改的学生
5. 使用 **Previous / Next** 按钮手动切换

**筛选模式：**
- **Ungraded**（默认）— 只显示尚未批改的学生
- **All** — 显示所有学生，包括已批改的

**退回作业：**
- 如果学生需要修改，点击 **Return** 将答案退回草稿状态
- 学生修改后重新提交时，系统会自动重新触发验证

### 进度追踪
- 每道题显示进度条：`█ 16/24 (67%)`
- 作业概览页显示所有题目的总体进度
- 全部批改完成后显示 **"All Clear!"** 提示

### 批量批改整道题
1. 在作业批改页，点击题目旁的 **Grade All** 按钮
2. 弹窗中输入统一分数
3. 该题下所有未批改的答案自动获得该分数

### 退回作业给学生
如果学生需要修改后重新提交，可以退回他们的作业：

**批改过程中退回：**
1. 在批改页面评分输入下方，点击 **Return** 按钮
2. 该答案恢复为草稿状态，分数被清除
3. 学生可以重新编辑提交

> 注意：退回作业会将 `isDraft` 设为 `true` 并删除已有分数。学生重新提交时，系统会自动将验证状态设为 `Pending`，确保 Lean 验证器重新检查代码。

## 快速参考

| 操作 | 方法 |
|------|------|
| 批改提交 | 侧边栏 → Review Workbench → 选课程 → 选作业 → 选题目 → 评分 |
| 退回作业 | 批改页面 → **Return** 按钮 |
| 添加学生到课程 | 课程 → Manage → Students → 搜索 → Add |
| 批量导入学生 | 课程 → Manage → Students → Batch Import |
| 创建作业 | 课程 → Manage → Assignments → Create Assignment |
| 创建练习 | 侧边栏 → Question Bank → Create Question |
| 发布通知 | 课程 → Manage → Notifications → Create Notification |
